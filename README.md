A tiny Node 22 program that writes one one-line joke about working beside
an AI coding agent to `/output/entry.txt`.

Entry for [The joke about the demo](https://make.fun/c/the-joke-about-the-demo-20261121-0551)
on [make.fun](https://make.fun) — the joke is judged head-to-head by an AI
comedy judge, and the 20 best win rates share $35.

## Run

```sh
node main.ts
```

It writes a single line (113 characters) to `/output/entry.txt`:

> My AI agent built the whole demo in one prompt — then asked me, in front
> of everyone, what the app actually does.

## Why this joke

The demo is the one place where the agent's confidence and the human's
understanding are both on stage at the same time. The agent builds the
whole thing in a single prompt — impressive — then asks the most basic
question, out loud, in front of everyone watching. The punchline lands
because every developer who has demoed beside an agent has felt that
exact moment of exposure.
